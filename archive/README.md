# Archive: earlier milestones (not part of the final experiment)

These folders are from earlier DS 340W milestones and are kept for the record. **They are not needed to
reproduce the results in our paper.** See the top-level `README.md`.

| Folder / file | What it was |
|---|---|
| `ambiqt-reproduction/` | Reproduction of the AmbiQT parent paper's col-synonyms baseline (LogicalBeam outputs) |
| `AmbiEnt/`, `ios_*`, `Basic_Interpretative_Openess_Scorer.ipynb` | Earlier interpretative-openness scoring experiments on AmbiEnt |
| `week11_datasets/`, `AmbiQT_datasets.zip` | Week 11 train/test/validation split |
| `evaluation/`, `scripts/` | Edit-F1 metric and generative-evaluation scripts |
| `AmbiQT_8192_Full_Experiment_original.ipynb`, `pilot_colab_original.ipynb` | Development notebooks, superseded by `DS340W_Demo.ipynb` |
